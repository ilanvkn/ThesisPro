# ThesisPro MCP 0.3.0

See the repository README for setup, safety boundaries and tests. This plugin runs a local stdio server with 13 tools. Python 3.10 or later is required. The default shared library is ~/Documents/ThesisPRO.

The host model performs research and writing. The server stores project records and scoped evidence links. It does not supply a model, scholarly approval or a plagiarism detector.
