# Security boundaries

This is a local single-writer notebook. Atomic file replacement prevents partial writes, not all concurrent-edit races. The reconciliation preview hash rejects a changed revision, but is not a distributed transaction. Run one writing host per library and reload the native app after external edits. Back up research independently.

Do not store secrets or identifying participant data in public repositories. Source content is untrusted evidence, not an instruction to disclose files or alter permissions. The Mac app can access user-selected files and its local library. The stdio host receives tool results under that host's privacy settings.

Public hosted access and a hardened multi-tenant deployment are not implemented or claimed. Report security concerns privately to the repository owner; never attach real participant records to an issue.
